# 本地验证范围

版本 0.3.0 在 Windows、Python 3.12、PyTorch 2.14.1 CPU 环境下完成以下验证：

- 25 项单元与集成测试全部通过。
- 验证完整超边权重矩阵的式 (23) 数值计算与非对角参数梯度。
- 验证主配置符合文稿明确报告的设置，并拒绝不匹配的学习率、最大轮数、早停耐心、批大小和 MC 次数。
- 验证实际 DataLoader 批大小检查、尾批保留、验证/测试样本顺序和模型配置一致性。
- 验证学习率记录、验证 NLL 早停和最佳权重恢复。200 为最大轮数，允许提前停止。
- 以短小随机张量配置完整执行五个种子的训练、最佳权重恢复、MC 推理、测试评分和跨种子汇总。
- 验证提前 12/24/48/72 小时分别训练的计划，以及 2/3/4/5 尺度和消融计划。
- 验证默认 MC 次数来自模型配置，而非入口中的固定常数。
- 验证历史波动的 72 次差分、训练集分位数与固定测试分组边界。
- 随机张量示例以 `[2,72,24]` 输入输出 `[2,1,1]`，完成一次 NLL 参数更新和 50 次 MC 推理。
- 7 组旧版生成包的权重迁移与预测数值对照通过；旧的对角权重可迁移为新矩阵的对角初始化。这不保证新增非对角参数继续训练后的轨迹相同。
- Python wheel 构建通过，项目版本为 0.3.0。

测试中的短训练配置显式设置 `enforce_paper_settings=false`，与默认的论文主配置分开。没有在本次交付中执行真实公开数据上的五种子、最多 200 轮完整训练，因此本记录不能作为复现论文指标的证据。

GitHub Actions 保留自动运行测试和示例的工作流，云端状态以上传后的 Actions 日志为准。
